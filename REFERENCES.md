# Motion references

The videos Bennett liked, and what to take from each. Use these as the style brief for Andri Academy videos.

| Reference | Link | Take from it |
|---|---|---|
| UI motion, one shape morphing (Tommy D. Rossi) | https://x.com/__morse/status/2103485566570369333/video/1 | Rounded floating UI, soft shadows, a cursor driving every change, calm cream background. Too busy for us as-is: keep the look, slow it down. |
| The prompt template behind that style (@twoclipping) | https://x.com/twoclipping/status/2103273003555402193/video/1 | "One shape, never cut", springs with at most a tiny overshoot, camera zooms so the state fills the frame. Banned: bouncy easing, glows, gradients on UI, dead time. |
| Prompt Motion gallery | https://prompt-motion.com/ | A library of code-made motion videos with their prompts. Good for ideas on single animations (text reveals, ticks, pills). |
| Legora Workflows launch video | https://www.youtube.com/watch?v=C4Xnn7XVWt0 | Split screens and fast pacing. Liked the motion graphics, but far too much going on for a teaching video. |
| Andri Document Creation v7 (Bennett's own) | local file, Desktop (Oct 2026) | Motion style of the callouts and the letter coming out of the app. |

## What worked in Academy 1.1 (approved 7 Oct 2026)

- Open straight on the yellow title card, mascot waving then the lightbulb. No question page before it.
- App window centred, no spinning wheel behind it. Cream to gold gradient background, never black.
- Screen changes push across (like opening a page in an app), never a plain fade.
- Zoom only where something must be read: the New Matter dialog and the source passage.
- One caption pill per step, appearing as the narration line for that step starts. It pops open from the number circle and morphs between steps.
- Every click shown; no step implied.
- Calm pace for narration (about 120 words a minute).
- End card: logo and mascot side by side, divider, Up next card with the time only (no level). Tick is the mascot's own artwork with no disc behind it, springing in.
- Headline second line in the same ink as the first, lighter weight. No grey text.
- Narration: ElevenLabs voice "English voice for Andri academy videos" (ID 8ZKCv6VSOJZaPFcJkcky).

## Watch for next time

- Script repetition. In 1.1 the word "matter" came up too often at the start ("Your first matter", "one matter", "Create a matter", "inside a matter"). Read the first 20 seconds of each script out loud and vary the wording (for example "case", "file", or rephrase) before generating the narration.

## Mascot artwork note (8 Oct 2026)

Bennett spotted it in 2.2. Don't use the lightbulb pose until the artwork is fixed; use the waving pose on title cards. 1.2 uses the lightbulb pose too.
