# Andri Academy 1.1 · Your first matter, start to finish

Final example video, approved 7 October 2026. Use it as the reference for the rest of the Academy series.

- `Andri Academy 1.1 - Your first matter (English UK).mp4`: 1920×1080, 60 fps, 1:21, UK narration, chapters built in, -14 LUFS.
- `website-ending-reference (up next card added by the website).png`: how the Academy website should show the next video after the MP4 ends. The MP4 itself ends on the logo, the mascot and the line "Andri Academy · Next: <next video title>"; the clickable card is added by the website.
- `Andri Academy 1.1 - timestamps.txt`: chapter timestamps to paste into the Academy page.

## How it was made

- Every frame drawn by JavaScript on a canvas, rendered with Playwright and FFmpeg.
- Andri screens rebuilt from real staging (mock case Nair v Calderdale Logistics).
- Narration: ElevenLabs, voice "UK voice voice to use for ANDRI vids" (My Voices), 8 Oct 2026.
- Source project, to edit or re-render: `Desktop/Andri/Motion Graphics/projects/2026-10-07-academy-1-1-first-matter/`
- Style references and what worked: `Desktop/Andri/Motion Graphics/REFERENCES.md`

## Note for the next scripts

The first version repeated "matter" a lot in the opening. The UK version rewords it ("Let's take one case", "for that case", "your own case"). Keep checking openings for repeated words.

## Script (as narrated, English UK)

0:00 Welcome to the Andri Academy.   (intro card: Andri icon + "Welcome to the Andri Academy")
0:03 First day in Andri, and no idea where to start?
0:06 Let's take one case, from start to finish.

0:18 Add the file. Upload it, or forward it by email. Andri reads every page.
0:28 Ask your first question. Not sure what to ask? Pick an example question. They're written for this case.

1:00 Then ask for a first letter. It's written in the background, and you open it from Jobs.
1:14 That's the whole loop. Now try it on your own case.
