I don't think I need to dig into case memory for this—it's a general question about the law, so I can answer directly, though I should flag that the ACAS Code's current wording (para 1) and any recent statutory amendments aren't something I've verified, so I'll keep the answer brief and note that caveat.
No, not to the redundancy dismissal itself. An uplift under s.207A TULR(C)A 1992 can still arise if a grievance or disciplinary element runs alongside it.
The statutory test. Section 207A(2) lets the tribunal increase an award by no more than 25% if the claim concerns a matter to which a relevant Code of Practice applies, the employer has failed to comply with that Code in relation to that matter, and the failure is unreasonable, where it considers an increase just and equitable. [2016] ICR 1016 Holmes v QinetiQ Limited The uplift therefore depends on the Code applying to the matter in the first place.
The Code excludes redundancy. Paragraph 1 of the Acas Code on Disciplinary and Grievance Procedures states: "This Code does not apply to redundancy dismissals or the non-renewal of fixed term contracts on their expiry." In Holmes v QinetiQ Limited [2016] ICR 1016 , the EAT (Simler P) read that paragraph as identifying two particular situations to which the Code does not apply: dismissals for redundancy and on the non-renewal of fixed term contracts on their expiry. Save for those two situations, it otherwise applies to all disciplinary and grievance situations. Holmes concerned a capability dismissal, so the redundancy point there is a description of the Code's scope, not the issue decided. It is EAT authority and binds the tribunals. I have not located a case where the redundancy exclusion was itself the ratio.
Where an uplift can still arise. The exclusion covers the dismissal, not everything around it. The indexed summary of Duhoe v Support Services Group Ltd [2015] UKEAT 102_15_1308 says the Code may apply to related grievance procedures. In Duhoe the tribunal found the dismissal was for no work and unfair for want of consultation, and the uplift question was remitted for proper reasons. I have only seen the headnote and background there, not the passage on the grievance point, so verify it before you rely on it. The practical consequences are these:
If the employee raised a grievance, for example about selection, scoring or pooling, and the employer failed unreasonably to follow the Code's grievance steps, s.207A can apply to that failure. De Souza v Vinci Construction (UK) Ltd [2017] EWCA Civ 879 shows grievance handling is a Code matter.
If the employer used "redundancy" as a label for what was in substance a conduct or performance dismissal, the exclusion should not protect it. This is a factual argument, not a point I have authority for.
The uplift applies only to jurisdictions listed in Schedule A2 (s.207A(1)). I did not retrieve that Schedule this turn, so confirm that your heads of claim are on it. Unfair dismissal is, but check any others.
