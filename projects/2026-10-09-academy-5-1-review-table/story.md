## Checked in Andri staging, 9 Oct 2026 (my own matter "Academy 5.1", shown as "Pennbridge Foods")

Demo setup (Bennett, 9 Oct): six short fictional supplier contracts for the client Pennbridge Foods Limited, written for this video (`demo-contracts/`), uploaded to a folder "supplier contracts" in my own matter. Every answer, passage, count and label below is what staging returned.

| Step in the brief | What staging shows |
|---|---|
| Matter sidebar → Review | Sidebar icon "Review" (table icon). With no reviews yet it opens straight on the empty grid; once a review exists it opens on a list with "Start new review". |
| The grid | "Sources" column, "Click to add a question", "Add another question", "Add a source"; top: "Add a source and a question to start", Try one cell, Start review. |
| Add sources | A panel slides in from the right: "Add sources", tabs Matter Knowledge Base / Company Knowledge Base / Case law, "Search documents and folders", Tags, Select all, "6 documents loaded", "Nothing selected.", Cancel, Use sources. Clicking the folder opens it (breadcrumb "Matter Knowledge Base › supplier contracts"); Select all → "6 of 6", "6 items selected". |
| Folder vs documents | Ticking the folder itself gives one row "All in supplier contracts · Expands at run time", but then Try one cell is off ("Pick at least one document (not just a folder) to preview."). The video selects the six documents. |
| Question panel | "Question 1": Format (Short text default, "A concise prose answer (default)."), Column header (optional), the question box ("What do you want to know about each source? Use @ to reference a specific document."), Done. From question 2: "Remove question". |
| Formats | Short text, Yes / No ("Force a yes/no answer with a short rationale."), Extract, Date ("One date per document, so the column sorts and filters by date."), Number ("One number per document, with its unit when the document gives one."), Choice list ("One of your own choices per document.", needs at least 2 choices). |
| Live header | Typing the header shows "Liability cap [Yes / No]" in the column at once; the question replaces "Click to add a question". Top line becomes "6 cells · 1 × 6", later "18 cells · 3 × 6". |
| Try one cell | Runs the top-left cell: "Andri is thinking…" with a Cancel preview link, then "✓ Yes · Clause 5.2 caps the Supplier's total liability at £100,000 in aggregate." and "Try again". About 8 to 11 s. |
| Start review | Opens the review page "Review – 6 documents × 3 questions": progress pill and bar (0/18), Cancel; cells "Queued", then "Andri is thinking…", then answers with "1 · Page 1" citations. Done in about 10 s: "Completed · 18/18 cells · 100%", Export, New review; each column gets sort, filter and remove icons. |
| Sources | Clicking a citation opens a panel: the question, the document, Answer, Citations with the exact passage and page ("5.2 Each party shall be liable…", Page 1). |
| Filter | Column filter: No 2 / Yes 4. Ticking No → "2 of 6 documents" (Corran Mills, Brightmoor Haulage), "Clear filter", and a "Review filtered" button (new review over the shown rows). |
| Add later | "Add another question" → Question 4; bottom bar "Run review on 6 new cells · 6 documents × 1 question · This will update the existing review." Run review → only the new column runs (Queued → thinking → answers, about 15 s); "24/24 cells". The old answers stay. |
| Export | One click on Export downloads `Review – 6 documents × 3 questions.xlsx` (no menu; no CSV choice in staging). Columns: Document, then each question and its "(reasoning)". |
| Not confirmed | "The review stays in the matter for 90 days" (not shown anywhere): left out. Review → client memo: left out (brief). |
