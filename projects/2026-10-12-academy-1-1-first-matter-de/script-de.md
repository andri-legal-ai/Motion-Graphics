# Academy 1.1 German: script and on-screen text

Written natively from the meaning of each English line (Bennett, 12 Oct 2026: rewrite, never word for word).
Formal "Sie" throughout, because the audience is lawyers. Each line still lands on the same step as in English.

## Narration (voice "german voice for andri vids", Eleven v4, one take)

| # | English (UK) | German |
|---|---|---|
| intro | Welcome to the Andri Academy. | Willkommen in der Andri Academy. |
| L0 | First day in Andri, and no idea where to start? | Ihr erster Tag mit Andri, und Sie wissen nicht, wo Sie anfangen sollen? |
| L1 | Let's take one case, from start to finish. | Wir gehen einen Fall einmal ganz durch. |
| L2 | Create a matter first. It's where Andri keeps everything for that case. | Legen Sie zuerst einen neuen Fall an. Dort sammelt Andri alles, was zu diesem Mandat gehört. |
| L3 | Add the file. Upload it, or forward it by email. Andri reads every page. | Dann kommt die Akte dazu. Laden Sie sie hoch oder leiten Sie sie per E-Mail weiter. Andri liest jede Seite. |
| L4 | Ask your first question. Not sure what to ask? Pick an example question. They're written for this case. | Stellen Sie Ihre erste Frage. Ideen finden Sie unter Beispielfragen, passend zu genau diesem Fall. Oder Sie schreiben einfach selbst, was Sie wissen möchten. |
| L5 | Click a source, and the document opens beside the chat, at the exact passage. | Klicken Sie auf eine Quelle, und das Dokument öffnet sich neben dem Chat, direkt an der richtigen Stelle. |
| L6 | Want Andri to read one document first? Type the at sign, and its name. | Soll Andri zuerst ein bestimmtes Dokument lesen? Tippen Sie ein At-Zeichen und den Namen des Dokuments. |
| L7 | Then ask for a first letter. It's written in the background, and you open it from Jobs. | Dann lassen Sie Andri einen ersten Brief entwerfen. Er entsteht im Hintergrund, und Sie öffnen ihn unter Jobs. |
| L7b | (letter on screen, new in German) | Der Brief steht auf Ihrer Kanzleivorlage, und jede Angabe stammt aus der Akte. |
| L8 | That's the whole loop. Now try it on your own case. | Das ist schon der ganze Ablauf. Probieren Sie es jetzt mit Ihrem eigenen Fall aus. |

Notes
- "matter" → "Fall": the German top bar and matters list say "Fälle" and "Neuer Fall". "Mandat" in L2 avoids saying "Fall" twice.
- "the file" → "die Akte" (the case file), not "die Datei".
- "Jobs" stays English because the app's rail tooltip says "Jobs" (the matter screens are not translated in staging).
- "At-Zeichen" is spelled out so the voice says it, not "@".
