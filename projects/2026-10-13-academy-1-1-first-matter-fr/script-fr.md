# Academy 1.1 French: script and on-screen text

Written natively in French from the meaning of each German/English line (Bennett: rewrite, never word for word), formal "vous",
each line on the same step as the German 1.1. Andri's own French terms are used wherever the app has them
(Dossiers, Nouveau dossier, Base de connaissances, Importer, Exemples de questions, Cabinet, Langue, Traitements).

Notes
- "matter" → "dossier" (Andri's French: Dossiers, Nouveau dossier). The opening says "une affaire" and L2 "ce mandat", so "dossier" isn't repeated three times in the first lines.
- "the file" → "les pièces" (the case documents), as a French lawyer says it.
- "Jobs" → "Traitements": the rail tooltip uses Andri's `common.jobs` key, which is "Traitements" in its French dictionary. (The Jobs panel's own title uses `jobs.title`, "Travaux"; both are shown as Andri has them.)
- "arobase" is said in full so the voice doesn't read "@".
