# Projects

One folder per piece: source, plates, audio and draft renders.

> **Every finished Academy video goes into `~/Desktop/Andri Academy videos (English)/`.** Each time a video is made here (1.1, 1.2, 2.1, 2.2 and so on), save the final MP4 into that folder, named by number only (`2.1.mp4`), with chapters built in. That folder holds only the videos. Put `2.1 timestamps.txt` in `~/Desktop/Andri Academy timestamps (English)/` and add the video's row to the README table there. The project folder in `projects/` keeps the source and draft renders only. A video is not finished until it is in that folder. (German, Dutch and French versions go into "Andri Academy videos (German)", "(Dutch)" and "(French)".)
